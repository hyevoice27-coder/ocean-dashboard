# 오션이의 하루

아침 준비·이번 주 숙제(8개)·칭찬 스티커·포켓몬 도감을 한 화면에서 보는 대시보드예요.
`index.html` 하나로 동작하고, 기록은 그 기기의 브라우저(localStorage)에 저장돼요.

- 이번 주 숙제 8개: 6개 기본 + 연산 프린트물(3장) + 폴리 영어(월~금)
- 주말 닌텐도: 8개 중 5개면 토요일 1시간, 8개 모두면 일요일 1시간
- 평일 08:00 · 08:15 알림(공휴일 제외): 차임벨 3회 + 화면 알림 + 한국어 음성 안내
  (음성은 `audio/alarm-0800.mp3` · `audio/alarm-0815.mp3` 파일로 재생 — 태블릿 TTS 설정이 필요 없어요)
- 홈 화면에 추가하면 앱처럼 열려요(PWA, 오프라인 캐시 · 음성 파일도 함께 저장)

## 온라인에서 열기

https://hyevoice27-coder.github.io/ocean-dashboard/

휴대폰·태블릿 크롬에서 위 주소를 열고 **메뉴 → 홈 화면에 추가**(또는 설치)를 누르면 앱처럼 열려요.
한 번 열어 두면 인터넷이 잠깐 끊겨도 화면이 떠요(service worker 캐시).

## 배포 메모

- 지금 GitHub Pages는 이 저장소의 `gh-pages` 브랜치 루트를 보고 있어요.
  `main` 을 배포 기준으로 쓰려면 저장소 **Settings → Pages → Source** 를 `main` / `/` 로 바꾸면 됩니다.
- 파일을 고칠 때는 `main` 과 `gh-pages` 를 같은 내용으로 맞춰 주세요.
